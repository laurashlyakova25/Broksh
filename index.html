🔐 Приватность, GitHub и личный токен

Публичный репозиторий на GitHub Pages хранит только структуру категорий и нулевые значения, чтобы чужие люди по ссылке не видели ваши суммы. Ваши реальные данные за 2024–2026 гг. и записанные чеки лежат в вашем личном JSON-файле данных и синхронизируются через ваш GitHub Personal Access Token (в приватный GitHub Gist) или локально в браузере.

☁️ Приватный GitHub Gist (синхронизация по токену)
Токен хранится только в вашем браузере (localStorage) и никуда не передаётся, кроме api.github.com.
